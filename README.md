# Summer Internship Assignment 1

This repository contains the solutions for the first Summer Internship Assignment. The assignment focuses on core Python concepts, data manipulation, visualization, web scraping, and data analysis.

## Project Structure

The assignment is divided into 10 tasks, which are covered by Jupyter notebooks and Python scripts:

- **Task 1: List & Dictionary Operations** (`Summer_Internship_Assignment_1_Task_1.ipynb`)
- **Task 2: File Handling** (`Summer_Internship_Assignment_1_Task_2.ipynb`)
- **Task 3: Functions & Error Handling** (`Summer_Internship_Assignment_1_Task_3.ipynb`)
- **Task 4: Debugging** (`Summer_Internship_Assignment_1_Task_4.ipynb`)
- **Task 5: Data Cleaning** (`task5_data_cleaning.py`)
- **Task 6: Data Visualization** (`task6_data_visualization.py`)
- **Task 7: Insights Report** (`task7_insights_report.py`)
- **Task 8: Web Scraper** (`task8_web_scraper.py`)
- **Task 9: Context Based Scraping** (`task9_context_scraping.py`)
- **Task 10: Data Summary & Analysis** (`task10_data_summary.py` and `task10_langchain_analysis.py`)

Additional directories and files:
- `data/`: Contains the datasets used for tasks 5-7.
- `plots/`: Stores visualizations generated by Task 6.
- `output/`: Output files generated from various tasks.
- `scraper_output/`: Contains JSON and CSV data as well as categorized media downloaded by the web scraper (Tasks 8-10).
- `keywords.txt`: List of keywords for context-based scraping.
- `requirements.txt`: Python package dependencies.
- `python_intern_assignment.pdf`: The original assignment instructions.

## Prerequisites

- **Python 3.10 or above**

## Setup and Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RKBehera223048/Summer_Internship_Assignment_1.git
   cd Summer_Internship_Assignment_1
   ```

2. **Create a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## How to Run

### Tasks 1 to 4
These tasks are implemented in Jupyter Notebooks. You can run them by starting Jupyter:
```bash
jupyter notebook
```
Then, open the respective notebook (`Summer_Internship_Assignment_1_Task_X.ipynb`) and run the cells.

### Tasks 5 to 7 (Data Analysis pipeline)
Run the Python scripts sequentially from your terminal:
```bash
python task5_data_cleaning.py
python task6_data_visualization.py
python task7_insights_report.py
```

### Tasks 8 to 10 (Web Scraping pipeline)
Run the scraping and summary scripts from your terminal:
```bash
python task8_web_scraper.py
python task9_context_scraping.py
python task10_data_summary.py
```
*(Note: Some of these tasks may require specific API keys or environment variables as configured in the scripts.)*
